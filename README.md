# College Transport Information System

A responsive web application for tracking college transport routes, bus timings, and transport request submission.

## Features

- Live route overview dashboard
- Filterable route listings
- Pickup and drop schedule table
- Student/staff transport registration form
- Responsive design for desktop and mobile devices

## Run locally

Open the project folder in a browser, or serve it with a local web server:

```bash
cd c:/Users/KILLS/manisha
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` – page structure
- `styles.css` – design and layout
- `app.js` – route data and interactive logic
